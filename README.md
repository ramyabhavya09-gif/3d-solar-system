
# 🌌 Interactive Solar System

An interactive, animated Solar System project built with HTML, CSS, and JavaScript. Explore the Sun and all eight planets, select planets to learn facts, and pause or resume their orbits.

## Features

- Animated orbits for all eight planets
- Interactive planet information
- Pause and resume controls
- Responsive mobile-friendly design
- No external libraries or API keys required

## Technologies Used

- HTML5
- CSS3 animations
- JavaScript

## Run the Project

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click a planet to learn more about it.

## Deploy on GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and open the published website.

## Project Structure

- `index.html` — page structure
- `style.css` — Solar System design and animations
- `script.js` — planet facts and interactions
- `README.md` — project documentation
